## 归档原则

- 属于具体项目的设计稿不放这里。
- 跨多个项目都可复用的完整说明文档放这里。
- 单个问题的简短解释不强行生成独立文件。
- 文件名含 `REBUILT` 表示根据历史对话重建，不是旧工作区逐字原件。
