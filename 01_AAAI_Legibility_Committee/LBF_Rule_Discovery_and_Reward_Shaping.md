# LBF、规则发现与奖励塑形

## 1. LBF 在项目中的角色

LBF 可以理解为多智能体协作环境中的一个实验平台。它适合研究：

- 多智能体之间如何协作。
- 行为是否具有可解释模式。
- Agent 是否能通过规则发现获得更可读的策略。
- 奖励塑形是否能引导 Agent 产生更符合人类理解的行为。

## 2. Rule Discovery 的目的

规则发现不是为了简单写死策略，而是为了从交互轨迹中总结出可解释的行为模式。

它回答的问题是：

```text
Agent 在成功完成任务时，是否存在稳定的行为规则？
```

可能的规则形式包括：

- 某类状态下 Agent 更倾向于移动到某个区域。
- 某种协作行为经常出现在成功轨迹中。
- 某些局部观察可以预测 Agent 的下一步行动。
- 某些行为序列会提高任务成功率或可读性。

## 3. Reward Shaping 的作用

Reward shaping 的目标是把发现的规则重新注入训练过程，使 Agent 不只是追求最终 reward，而是在学习过程中被引导到更可读、更稳定的行为轨迹上。

可以理解为：

```text
环境原始奖励
  +
规则导出的 shaping reward
  =
新的训练信号
```

这样做的关键不是简单加奖励，而是要避免破坏原始任务目标。

## 4. Rule Discovery 与 Reward Shaping 的关系

两者关系如下：

```text
训练 / 采样轨迹
  ↓
发现候选行为规则
  ↓
筛选有效规则
  ↓
根据规则构造 shaping reward
  ↓
重新训练或微调 Agent
  ↓
评估任务性能与可读性
```

## 5. 论文中应该强调的点

1. 规则发现提供了可解释结构。
2. 奖励塑形提供了训练层面的干预方式。
3. 可读性不是后处理解释，而是在训练过程中被引导形成。
4. 实验应该同时报告任务性能和可读性指标。

## 6. 潜在风险

- 发现的规则可能只是数据集偏差。
- Reward shaping 可能引入 reward hacking。
- 可读性提升可能牺牲任务性能。
- 规则可能只适用于特定环境规模。

## 7. 后续需要从代码确认的内容

- 规则是如何表示的。
- 候选规则如何生成。
- 规则如何评分。
- Shaping reward 如何计算。
- 训练是否分阶段进行。
- 输出日志包含哪些指标。
