# 04_AgentOS_OSAgent

这个目录用于整理 AgentOS 与 OS Agent 方向。

## 项目定位

AgentOS 和 OS Agent 是两个相关但不同的方向。

- AgentOS：为 Agent 重新设计系统层能力。
- OS Agent：让 Agent 在现有操作系统上操作电脑、浏览器、文件和应用。

## 核心判断

未来如果 Agent 能力成熟，AgentOS 可能成为真实方向。它意味着用户不再需要频繁打开 App、管理账号和手动组织任务，而是表达目标，由 Agent 调度系统能力完成。
