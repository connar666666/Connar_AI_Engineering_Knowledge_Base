# OS Agent

## 1. OS Agent 是什么

OS Agent 是在现有操作系统上运行的 Agent。它不重写 OS，而是通过屏幕理解、键鼠控制、终端操作、浏览器操作等方式完成任务。

## 2. OS Agent 的典型能力

- 看屏幕。
- 点击按钮。
- 输入文字。
- 操作浏览器。
- 管理文件。
- 调用终端。
- 使用已有软件。
- 自动完成重复任务。

## 3. 和 AgentOS 的区别

OS Agent 是：

```text
在旧系统上加 Agent。
```

AgentOS 是：

```text
为 Agent 重新设计系统。
```

OS Agent 更现实，短期更容易落地；AgentOS 更底层，长期影响更大。

## 4. OS Agent 的优势

1. 不需要重写操作系统。
2. 可以直接使用现有 App。
3. 落地速度快。
4. 可以和浏览器、终端、文件系统结合。

## 5. OS Agent 的限制

1. UI 变化会导致失败。
2. 视觉理解不稳定。
3. 权限和安全边界复杂。
4. 操作速度慢于原生 API。
5. 错误操作风险较高。

## 6. 未来方向

OS Agent 可能是通向 AgentOS 的中间阶段。随着系统接口逐步开放，Agent 会从“模拟人类操作”转向“直接调用系统能力”。
