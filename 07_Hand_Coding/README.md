# 07_Hand_Coding

这个目录整理手撕代码、数据结构、算法和 Python 工程基础的增量学习记录。

## 学习原则

不只记最终代码，而是保存：

- 为什么选择这个数据结构。
- 每个变量在循环中的不变量。
- 常见错误是如何产生的。
- 如何构造输入输出和测试。
- 面试时如何解释复杂度与设计取舍。
