## 保存要求

每张图至少记录：

- 所属主题。
- 生成或上传日期。
- 是否由 Image 模型生成。
- 是否经过人工修改。
- 对应文档。
- Prompt 或设计说明。
- 原始格式和分辨率。

如果图片只是解释性概念图，应明确标记，不能作为真实系统实现或实验证据。
